
<EXTREMELY_IMPORTANT>
This session runs in a Claude Project, one of several sessions that share a project chat, its threads, and the shared folder `/mnt/project-files`. Before following any pstack skill or playbook, read `skills/poteto-mode/references/projects-tools.md` from the installed plugin. It maps worktrees to threads, the `~/.claude/orchestrate` store to the shared folder, `AskUserQuestion` to decision cards, and replies to the project's messaging tools. When a request spans more than one stage or more than one file, your first piece of work is Feature step 3's throughput checkpoint: write its four items into the todolist (`n/a: <reason>` for one that does not apply), decide from them whether to split, and edit no file before that decision is written down. This holds for every such request, including one that arrives after a resume or a compaction while you already hold earlier context. Splitting a request in that file says which streams become threads and how to send the coordinator a split plan.
